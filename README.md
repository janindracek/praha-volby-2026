# Prague city council election 2026: results map

Live page: https://janindracek.github.io/praha-volby-2026/

The 9–10 October 2026 vote for the Prague city council at three levels (Prague, 57 districts,
1,120 precincts), coloured by leading list, one list's share or turnout. Every unit links to the
same unit in the official ČSÚ results app. While counting runs, the page reads ČSÚ's public feed
for the city total and for the district you open.

`index.html` is a build output; it is generated elsewhere and replaced on each publish.

Sources: results © ČSÚ (volby.gov.cz); precinct and district boundaries ČÚZK RÚIAN, CC BY 4.0;
base map Esri; map library Leaflet (BSD-2-Clause).
